# Historical legacy-v1 study — not the current headline results

Preserved without replacing measured values. The earlier protocol redraws
partitions per seed and uses equal-batch validation averaging. Do not pool its
seeds or compare its depth setting causally with final-v2: multiple protocol
choices changed.

- `metrics.json`: historical main study.
- `figures/`: historical figures, not the current README figures.
- `reference/`: frozen legacy selection and reproduction notes. The notes
  describe the old study and must not be read as final-v2 conclusions.
- `parallel/`: saved historical reproduction artifacts; large score arrays
  remain ignored by Git.
- `superseded/`: older development artifacts, retained as provenance only.

For current results, use [../final-v2/](../final-v2/README.md).
